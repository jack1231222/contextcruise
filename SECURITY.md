# Security Reports

Do not publish exploit details, conversations, databases, or credentials in a public issue.

GitHub Private Vulnerability Reporting is enabled for this repository. Use the [private reporting form](https://github.com/jack1231222/contextcruise/security/advisories/new) to notify the maintainer. Share only the minimum information required to reproduce the issue. Do not attach real conversations, authentication files, databases, API keys, or other credentials.
