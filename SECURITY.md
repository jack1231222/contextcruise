# 安全问题

请不要在公开 Issue 中发布漏洞利用细节、对话、数据库或凭证。

本仓库已启用 GitHub Private vulnerability reporting。请通过 [私密报告入口](https://github.com/jack1231222/contextcruise/security/advisories/new) 向维护者说明安全问题，仅提供复现所需的最少信息，不附真实对话、认证文件、数据库或密钥。

Private vulnerability reporting is enabled. Use the [private reporting form](https://github.com/jack1231222/contextcruise/security/advisories/new), not a public Issue, for security concerns. Share only the minimum information needed to reproduce the issue; do not attach real conversations, authentication files, databases, or credentials.
