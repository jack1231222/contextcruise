# Scope and limitations

11.21.45 is an Apple Silicon statistics beta with a Simplified Chinese interface. Its deployment target is macOS 14. This build was exercised on the development Mac; a clean macOS 14 installation has not been tested. The older beta's macOS 13 validation applies only to that older build.

Statistics depend on local logs and sampling. API-equivalent costs are estimates. Optional remote reporting requires a compatible service configured by the user.
