# 安装与使用

当前候选10015已签名、公证并通过更新异常与恢复验证；最终macOS13.4.1安装、真实脱敏快照读取与退出重开验证通过。下述10014系统验证另作历史基线保留。

10014 公证安装包已在 macOS 13.4.1 干净虚拟机完成安装、内置运行时、合成记录和界面验证。真实 Codex 集成与外置 APFS 上的 Sparkle 升级沿用既有证据，详见已知限制。当前尚未公开发布，以下下载流程须等 Release 发布后使用。

1. 在官方 Releases 核对版本、Apple Silicon 与该版本实际验证的 macOS 范围。
2. 下载 `ContextCruise-<版本>-macOS-arm64.dmg`，打开后将 ContextCruise 拖入“应用程序”。退出旧版后打开新版本。
3. 首次选择 Codex 数据目录。默认建议用户主目录下的 `.codex`；隐藏目录可通过选择器显示。需要可读取的 `sessions`，后续还需当前 Codex 目录库、账号身份和实时状态接口兼容。
4. 等待首次索引完成。刚启动时可能暂时显示“未知”或“正在同步”；这不等于对话已经结束。列表范围遵循当前适配的 Codex 跟进规则，不等于所有历史对话。
5. 用搜索、收藏和详情查看记录。暂停监测停止本地刷新；关闭窗口可继续后台监测，退出 App 才停止后台进程。

## AI

本地统计不产生 AI 调用。AI 默认关闭；要使用时先在 API 配置中设置服务、凭证、模型和预算，再明确启用自动分析。服务商单独计费。不要把隐私敏感材料发送给未经信任的服务。关闭分析不会删除已保留的建议。

## 更新

发行完成后，“检查更新”使用 Sparkle。自动检查由用户选择，自动安装默认关闭。“接收测试版更新”默认关闭；开启后使用独立测试更新源。取消更新保留当前程序。发现签名错误时不要绕过验证。

10015 已配置正式更新地址，但公开更新源尚未发布，当前不能依靠该地址获取更新。稳定与测试渠道切换不强制降级。

## 导入旧版数据

仅在首次连接 Codex 之前，从应用菜单选择“导入旧版非敏感数据”，选择旧版运行数据目录。只导入白名单设置与结构可验证的统计库；不导入凭证、API 配置或请求账本，AI 保持关闭。导入后退出并重开，再连接 Codex。目标已有数据会拒绝覆盖；旧版文件保留。暂不提供两个非空数据集的合并。

## 卸载与回退

退出 App 后将应用移到废纸篓。设置与统计默认保留在 `~/Library/Application Support/ContextCruise`；钥匙串中的专用凭证也不会随应用拖走而自动删除。删除数据或钥匙串项目会丢失相关内容，请先自行备份并确认。

升级前保留当前版本和数据备份。需要回退时先另存新版本产生的数据；不要把旧备份直接覆盖后来产生的记录。尚未验证的跨版本回退不保证兼容。
